    Biztonság röviden

    • Feltöltés csak a projektmappából, valamint a Letöltések, az Asztal és a Dokumentumok mappából. Rejtett fájlt (például .env vagy .ssh) csak akkor, ha külön engedélyezed.
    • A jelszómezők értéke semmilyen kimenetben nem jelenik meg.
    • Indítási módban nincs hálózati hibakereső port: a Chrome-mal egy belső csövön beszél.
    • Nincs álcázás és nincs botfelismerés-kijátszás: ez a te böngésződ, a te bejelentkezéseiddel.

    Fogalomtár

    MCP (Model Context Protocol)
    Nyílt szabvány arra, hogy egy AI-alkalmazás külső eszközöket és adatokat érjen el. Az Anthropic adta ki 2024 végén. Gyakori hasonlat: olyan, mint az USB-C, csak AI-eszközöknek.
    Host
    Az alkalmazás, amit használsz, itt a Claude Code. Ő beszél a modellel, és ő indítja a szervereket.
    MCP kliens
    A hoston belüli kapcsolat egy szerverhez. Minden szerverhez külön kliens tartozik.
    MCP szerver
    Külön program, ami eszközöket kínál, itt a Motorika. Futhat a gépeden (stdio), vagy távolról, HTTP-n keresztül.
    Eszköz (tool)
    Név, leírás és bemeneti séma (JSON Schema). Az eszközt a modell választja ki. Az MCP erőforrásokat és promptokat is ismer, de a Motorika csak eszközöket használ.
    JSON-RPC 2.0
    Az üzenetek formája. Kérés: id, method, params. Válasz: ugyanaz az id, és result vagy error. Értesítés: id nélkül, nem jár rá válasz.
    stdio
    A program szabványos bemenete és kimenete. Helyi MCP szervereknél ez a vezeték: soronként egy JSON üzenet. Ezért a szerver semmi mást nem írhat a kimenetére.
    tool_use és tool_result
    Az eszközhívás a modell oldalán: a modell tool_use blokkot ír, a válasz tool_result blokként érkezik vissza.
    Playwright
    A Microsoft böngészővezérlő könyvtára. A Motorika ezzel beszél a Chrome-mal, és ez végzi az automatikus várakozást is.
    CDP
    Chrome DevTools Protocol, a Chrome saját vezérlőnyelve. Indítási módban egy belső csövön megy, nincs hálózati port.
    Ref (például e12)
    Egy elem azonosítója a pillanatképben. Az egész munkamenetre egyedi, ezért a szerver azt is tudja, melyik fülön van.
    Headless
    Ablak nélküli Chrome. Gyorsabb és nem zavar, de nem látod, mit csinál. Az alapértelmezés az ablakos mód.
    Állapot: 2026. október 21. Az első verzió most épül (a szerver és a tőle független elfogadási tesztek); a közös böngésző a második fázisban jön. Az üzenetek a 2025-11-25-ös MCP protokollverziót követik, egyszerűsítve; a konkrét értékek példák.
